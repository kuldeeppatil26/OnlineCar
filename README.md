# Loopcar

React + Vite frontend for the Loopcar self-drive car rental platform.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

Push this repository to GitHub on the `main` branch. The included GitHub Actions workflow builds and deploys the site to GitHub Pages.

Note: the current app is a frontend/demo. Real OTP SMS, payment processing, database storage, KYC/face verification and production authentication require backend services.
